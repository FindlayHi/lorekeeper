# Security

## Reporting a problem

Please report security problems privately, using GitHub's private vulnerability reporting: open the **Security** tab of this repository and choose **Report a vulnerability**. Please do not open a public issue for it.

Include what you found, how to reproduce it, and the Lorekeeper version (tray menu). You should get a reply within a week or so.

## What is in scope

- the Lorekeeper app
- the updater, and the checks it makes on the installer it downloads
- the installer
- the cartridge and lore files served from the project's site (`cartridges.json` and the lore packs)

## Not in scope

Problems in the AI providers, wikis or games Lorekeeper talks to, and anything that needs an attacker to already control your PC.

## Bounty

This is a free, volunteer project, so there is no bounty. Credit in the fix notes is yours if you want it.
